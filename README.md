# 📸 ComposeScreenshotOfficial


> Demonstrates the **official Jetpack Compose Screenshot Testing** plugin  
> `com.android.compose.screenshot` (`0.0.1-alpha10`) for automated Compose UI visual verification.

---

## 🧭 Overview

**ComposeScreenshotOfficial** is a sample project showing how to integrate and use  
the **Compose Preview Screenshot Testing** plugin in a modern Android app.

This official solution by Google enables developers to:
- 📸 Capture screenshots of **Composable Previews** automatically.
- 🧱 Generate and compare **golden baselines** directly from Gradle.
- 🧪 Detect **UI regressions** across themes, devices, and configurations.
- ⚙️ Integrate seamlessly with **Compose Previews** — no extra test code needed.

---

## 🧰 Tech Stack

| Component | Purpose |
|------------|----------|
| **Jetpack Compose** | Declarative UI framework |
| **com.android.compose.screenshot** | Official screenshot plugin |
| **Compose Preview Annotations** | Define testable UI states |
| **Gradle 8.7+** | Build and automation |
| **Kotlin DSL** | Modern build configuration |
